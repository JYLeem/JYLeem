**Testing**

두 레포 모두 GitHub Actions로 push마다 테스트가 돌아갑니다. 고급알고리즘 수업 과제로, AI 코딩 에이전트에 테스트 전략을 지시하고 결과를 직접 검증하며 만들었습니다.
